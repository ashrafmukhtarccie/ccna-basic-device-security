# Basic Device Security

## Overview

This lab focuses on applying basic security configurations to Cisco network devices using Cisco IOS.

## Objectives

* Configure device passwords
* Secure console and VTY access
* Encrypt passwords
* Configure privileged EXEC access
* Verify security settings

## Tools

* Cisco Packet Tracer
* Cisco IOS

## Outcome

Configured and verified basic security measures on Cisco network devices.
